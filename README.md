# Интерактивная физиология сердечно-сосудистой системы

Новый независимый учебник нормальной физиологии для студентов 2 курса. 25 модулей, 17 подразделов на модуль, RU/EN/KZ. Функциональная анатомия и клинические примеры дополняют нормальную физиологию.

## Статус
Первоначальный навигационный каркас. Полные тексты теории, тесты, виртуальные лаборатории, виртуальные пациенты, экзаменационный центр, проверка качества переводов и научных источников — **планируются и ещё не реализованы**. Пустые разделы нельзя считать готовым учебным материалом.

## Разработка
`npm install` → `npm run dev`; для production: `npm run build`.

Новые материалы готовятся оригинальным текстом по признанным руководствам физиологии, с проверкой научных ссылок и прав на изображения.
